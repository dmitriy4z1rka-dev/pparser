# Проверки

## Локальные тесты

Из корня репозитория:

```bash
python3 -m unittest discover -s tests -v
python3 -m compileall -q leadgen scripts tests
docker compose config --quiet
```

Unit-тесты проверяют нормализацию и IDNA-домены, объединение наблюдений разных источников, метрики рейтинга по источникам, миграцию сохранённых SQLite-данных, очередь синхронизации, продолжение заданий и обработку ошибок API.

## Проверки работающей CRM

После запуска Compose:

```bash
docker compose exec -T collectors python - < scripts/check_crm.py
docker compose exec -T collectors python - < scripts/check_ui.py
```

`check_crm.py` создаёт случайно названные тестовые лиды и задачу, проверяет API, метрики Яндекса/2ГИС и ограничения интеграционной роли, затем удаляет записи. `check_ui.py` использует Chromium: проверяет панель статусов, сохранение Enter, Shift+Enter в заметке, открытие CRM без входа и сохранение данных после перезагрузки и в новом контексте браузера. Снимки браузера создаются в `/data/test-artifacts` внутри контейнера.

Проверка перезапуска всех сервисов, включая MariaDB:

```bash
python3 scripts/check_persistence.py
```

Она останавливает Compose-сервисы, создаёт тестовые записи и удаляет их после проверки. Не запускайте её во время сбора; тома не удаляются.
