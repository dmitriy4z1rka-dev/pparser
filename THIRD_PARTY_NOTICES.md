# Сторонние компоненты

В `vendor/` находятся исходные проекты, на которых основана интеграция. Их исходные README и доступные файлы лицензий сохранены вместе с кодом.

| Компонент | Исходный проект | Лицензия в исходном снимке |
|---|---|---|
| Парсер Яндекс Карт | [dmikhaylov/yamaps_parser](https://github.com/dmikhaylov/yamaps_parser) | Файл лицензии в полученном снимке отсутствовал. Проверьте условия у автора перед публичным распространением. |
| Парсер 2ГИС | [Eroloft/parser-2gis-new](https://github.com/Eroloft/parser-2gis-new) | LGPLv3; файл `vendor/parser-2gis-new/LICENSE` сохранён. |
| CRM-кастомизация | Локальный слой для EspoCRM | Используется официальный образ `espocrm/espocrm:10.0.11`; лицензия платформы и требования к распространению её производных компонентов описаны в документации EspoCRM. Сам образ в репозиторий не копируется. |

Для корневого приложения отдельная лицензия пока не выбрана. Не добавляйте лицензию автоматически: сначала определите, на каких условиях автор хочет распространять собственные изменения и убедитесь, что это совместимо с включёнными сторонними компонентами.
